# Prepare a proposal

Resolve this skill directory's symlinks before opening relative references.
Read the [shared entry rules](../entry-rules.md), then follow
[Prepare a proposal](../../feature_execution_blueprint.md#prepare-a-proposal),
including discovery/interview, document ownership, readiness and approval presentation.
That section owns the procedure; do not load delivery or unrelated batches.

Use the supplied business need or issue reference. If existing records and the
request do not identify it, ask. Present the preliminary behavior, technical changes,
interfaces and relevant flow before asking focused questions. Keep unresolved work
`planned`; present the settled proposal at `awaiting_approval`. Preparation does
not authorize implementation or publication.
